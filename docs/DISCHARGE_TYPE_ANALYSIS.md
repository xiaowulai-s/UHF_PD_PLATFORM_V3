## 1. 背景与原理

### 1.1 PRPD 图谱与放电类型的关系

**PRPD（Phase Resolved Partial Discharge）** 即相位分辨脉冲序列，通过在工频电压周期内记录放电脉冲的**相位角**和**幅值**，形成二维分布图谱。不同绝缘缺陷产生的放电具有特征性的相位分布规律，是识别放电类型的核心依据。

```
工频周期 (0-360°)
│
├─ S1 (0°-60°)     正半周起始段  → 内部气隙、沿面
├─ S2 (60°-120°)   正半周中间段
├─ S3 (120°-180°)  正半周末尾段
├─ S4 (180°-240°)  负半周起始段  → 内部气隙、沿面
├─ S5 (240°-300°)  负半周中间段
└─ S6 (300°-360°)  负半周末尾段  → 电晕放电
```

### 1.2 分类算法总览

**策略**: 参考剖面匹配（Profile Matching）

```
输入: PRPD 数据 (相位 N 维数组, 幅值 N 维数组)
  │
  ▼
特征提取 (_extract_features)
  │  输出: 八维特征向量 {quad13, spread, top2, symmetry,
  │          s1_s4_ratio, cv, pos_energy, neg_tail}
  │
  ▼
噪声拒判 (Noise Rejection)
  │  条件: top2 < 0.40 AND max_amp < noise_threshold × 5
  │  通过: 继续分类
  │  拒绝: 返回 "纯噪声"
  ▼
剖面匹配 (_compute_similarity)
  │  计算: 与 4 种参考剖面的高斯核相似度
  │  输出: {corona: 0.29, internal: 0.57, surface: 0.30, floating: 0.42}
  │
  ▼
Softmax 归一化
  │  温度参数 T=5.0
  │  输出: 概率分布 {corona: 14%, internal: 57%, surface: 30%, floating: 42%}
  │
  ▼
决策 (最高概率)
  │  输出: 参考结果 + 置信度 + 严重等级
  └─→ 参考结果 (reference_result)
        - type: "internal"
        - name: "内部气隙放电"
        - confidence: 57%
        - severity: "warning"
```

### 1.3 Bootstrap 50 次采样（统计聚合）

为提高分类稳定性，采用 **Bootstrap 重采样**：

```
全量数据 (N 条事件)
  │
  ├─ 有放回抽样 50 次，每次抽取 ~N/8 条
  │     │
  │     ├─ 样本 1 → classify() → 类型 A
  │     ├─ 样本 2 → classify() → 类型 B
  │     ├─ ...
  │     └─ 样本 50 → classify() → 类型 A
  │
  ▼
统计聚合
  - type_counts:  {A: 35, B: 12, C: 3}
  - type_ratios:  {A: 70%, B: 24%, C: 6%}
  - scores:       各类型得分均值（50 次的平均）
  - reference_result: 多数投票结果 + 置信度（最高占比）
```

## 2. 六扇区相位模型

### 2.1 扇区定义

将工频周期 0°~360° 均匀划分为 **6 个扇区**：

| 扇区 | 相位范围 | 物理意义 | 典型放电关联 |
|------|---------|---------|-------------|
| **S1** | 0°~60° | 正半周起始段 | 内部气隙（最强）|
| **S2** | 60°~120° | 正半周中间段 | - |
| **S3** | 120°~180° | 正半周末尾段 | - |
| **S4** | 180°~240° | 负半周起始段 | 内部气隙（次强）|
| **S5** | 240°~300° | 负半周中间段 | 电晕尾部 |
| **S6** | 300°~360° | 负半周末尾段 | 电晕放电（最强）|

### 2.2 扇区能量计算

对每个扇区 i（0~5），计算该区间内所有放电事件的**幅值加权能量**：

```
扇区能量[i] = Σ(幅值[j])，其中相位[j] ∈ [i×60°, (i+1)×60°)
S1 = W1 / (W1+W2+W3+W4+W5+W6)   (归一化)
S2 = W2 / total
...
S6 = W6 / total
```

> 注：使用幅值加权（而非单纯计数）更能反映放电强度。

## 3. 八维特征向量

### 3.1 特征定义与物理意义

| 特征 | 物理意义 | 计算方式 | 典型范围 |
|------|---------|---------|---------|
| **quad13** | S1+S4 集中度（正负半周起始段合计能量占比） | `S1 + S4` | 0~1 |
| **spread** | S2+S3+S5+S6 扩散度（中间段能量占比） | `S2 + S3 + S5 + S6` | 0~1 |
| **top2** | 最大两扇区集中度（最高能量两扇区合计） | `sum(top2扇区能量)` | 0~1 |
| **symmetry** | 正负半周对称性 | `1 - |S1-S4|/(S1+S4)` | 0~1 |
| **s1_s4_ratio** | S1/S4 比值（正负起始段能量比） | `S1 / (S4 + ε)` | 0~∞ |
| **cv** | 幅值变异系数（相对离散程度） | `std(幅值) / mean(幅值)` | 0~∞ |
| **pos_energy** | 正半周能量占比 | `Σ(0°-180°幅值) / Σ(全部幅值)` | 0~1 |
| **neg_tail** | 负半周尾部集中度（S5+S6 占比） | `S5 + S6` | 0~1 |

### 3.2 辅助特征（不参与匹配，用于分析）

| 特征 | 用途 |
|------|------|
| S1~S6 | 各扇区单独能量（用于人类可读报告） |
| pos_ratio | 正半周占比（S1+S2+S3） |
| s1_dominance | S1 在正半周内的主导度 |
| corona_tail | S6/(S5+S6) — 电晕尾部特征 |
| s1_ratio | S1/(S1+S4) — 正半周起始段比例 |
| asymmetry_ratio | 幅值加权不对称性 |
| bimodality | 双峰性（幅值分布） |
| noise_removed | 去噪后剩余事件数 |
| clean_events | 去噪后事件总数 |
| max_amp / p90 | 幅值极值统计 |
| amp_median | 幅值中位数 |

### 4.2 物理机理与 PRPD 特征

#### 4.2.1 内部气隙放电（Internal Discharge）

**物理机理**：
- 绝缘介质（如环氧树脂、油纸）内部存在气泡或杂质
- 气泡击穿电压低于周围介质，形成局部放电
- 每次工频周期内正负半周各发生一次放电（对称性）

**PRPD 图谱特征**：
```
相位分布:
  S1 (0°~60°) ████████████████████ 强集中
  S2~S3       稀疏分布
  S4 (180°~240°) ████████████████   次强集中（S1 > S4）
  S5~S6       稀疏分布

特征量:
  quad13 = 0.75  （S1+S4高度集中）
  s1_s4_ratio = 1.45  （核心判据：S1明显大于S4）
  top2 = 0.75
  spread = 0.25
  cv < 1.0 （幅值稳定）
  pos_energy ≈ 0.5 （正负能量均衡）
```

**典型场景**：
- 电缆终端环氧套管内部气泡
- 变压器油中气泡放电
- GIS 中绝缘子内部缺陷

---

#### 4.2.2 电晕放电（Corona Discharge）

**物理机理**：
- 高压导体表面曲率半径小（尖端、边缘），电场集中
- 尖端附近空气电离，形成电晕
- 负半周电子崩发展更充分，负电晕占主导

**PRPD 图谱特征**：
```
相位分布:
  S1~S3       几乎无放电
  S4~S5       少量分布
  S6 (300°~360°) ████████████████████ 强集中（负半周末尾）

特征量:
  quad13 = 0.32  （S1+S4占比低）
  pos_energy = 0.25  （核心判据：正半周极少）
  neg_tail = 0.33 （S5+S6显著）
  top2 = 0.38
  spread = 0.68
  cv = 1.50 （幅值变异中等）
```

**典型场景**：
- 母线端部尖端放电
- 导线损伤或毛刺
- 开关柜触头边缘

---

#### 4.2.3 沿面放电（Surface Discharge / Creepage）

**物理机理**：
- 绝缘子表面污秽或受潮
- 表面电场畸变导致局部放电
- 正半周强、负半周弱或不对称

**PRPD 图谱特征**：
```
相位分布:
  S1 (0°~60°) ████████████████████████████████ 极高度集中
  S4~S6       分散或不对称分布

特征量:
  quad13 = 0.88  （S1+S4极高集中度，最高）
  spread = 0.12  （极低扩散）
  top2 = 0.88    （极高集中度）
  symmetry = 0.95  （极高对称性）
  s1_s4_ratio = 1.05  （核心判据：S1≈S4，高对称）
  cv = 0.50 （极低变异，幅值稳定）
  neg_tail = 0.06 （S5+S6极少）
```

**典型场景**：
- 瓷套外表面污秽
- 复合绝缘子护套破损
- 潮湿环境下绝缘子表面爬电

---

#### 4.2.4 悬浮颗粒放电（Floating Discharge）

**物理机理**：
- 金属悬浮电位体（如螺栓、金属屑、未接地的屏蔽层）
- 通过电容耦合与高压导体形成电位差
- 放电发生在电位差最大的相位，但悬浮体电位不稳定

**PRPD 图谱特征**：
```
相位分布:
  0°~360° 均有分布，无明显集中区间

特征量:
  quad13 = 0.38  （低集中度）
  spread = 0.62  （高扩散）
  top2 = 0.40    （低集中度）
  symmetry = 0.90 （较对称）
  **cv = 2.50**  （核心判据：极高变异系数）
  pos_energy = 0.49 （正负能量均衡）
  neg_tail = 0.31
```

**典型场景**：
- 开关柜内未接地金属件
- 电缆接头铜编织带松动
- 变压器内部金属异物

```python
FEATURE_SIGMAS = {
    "quad13": 0.15,       # 严格
    "spread": 0.15,       # 严格
    "top2": 0.15,         # 严格
    "symmetry": 0.15,     # 严格

```

**设计原理**：
- σ 越小，匹配越严格（类型区分度越高）
- `pos_energy` 使用最严格的 σ=0.10，因为这是区分电晕的核心判据
- `cv` 使用最宽松的 σ=0.80，因为幅值变异系数受多种因素影响

## 6. 相似度匹配算法

### 6.1 加权高斯核相似度计算

对于特征向量 `F = {f1, f2, ..., f8}` 和参考剖面 `P = {p1, p2, ..., p8}`：

```
score = Σ(weight_i × exp(-(f_i - p_i)² / (2 × σ_i²))) / Σ(weight_i)
```

**公式展开**（以 pos_energy 为例）：

```python
diff = features["pos_energy"] - profile["pos_energy"]  # 特征差值
sigma = FEATURE_SIGMAS["pos_energy"]  # σ = 0.10
weight = FEATURE_WEIGHTS["pos_energy"]  # w = 1.3

similarity = weight × exp(-diff² / (2 × σ²))
            = 1.3 × exp(-(0.25 - 0.30)² / (2 × 0.10²))
            = 1.3 × exp(-0.0025 / 0.02)
            = 1.3 × exp(-0.125)
            = 1.3 × 0.882
            = 1.147
```

**归一化**：所有特征的加权相似度之和除以总权重，得到 [0, 1] 的最终得分。

### 6.2 Softmax 归一化（概率化）

原始得分 → 概率分布（温度参数 T=5.0）：

```python
exp_scores = exp(raw_scores × T)
probabilities = exp_scores / sum(exp_scores)
```

**温度参数作用**：
- T 越大，概率分布越平滑（区分度降低）
- T 越小，概率分布越尖锐（区分度提高，但可能过拟合）
- T=5.0 在区分度和稳定性之间取得平衡

**示例**：
```
raw_scores = [0.29, 0.57, 0.30, 0.42]  # 四种原始得分
exp_scores = exp([0.29×5, 0.57×5, 0.30×5, 0.42×5])
           = exp([1.45, 2.85, 1.50, 2.10])
           = [4.26, 17.28, 4.48, 8.17]
probabilities = [4.26, 17.28, 4.48, 8.17] / 34.19
            = [12%, 51%, 13%, 24%]
```

## 7. 判断条件与决策逻辑

### 7.1 噪声拒判条件

```python
# 噪声拒判发生在特征提取之后、剖面匹配之前
noise_threshold = max(amp_median × 2.0, p5 × 1.5, min_nonzero)

if top2 < 0.40 and max_amp < noise_threshold × 5:
    return {
        "type": "noise",
        "name": "纯噪声",
        "description": "信号为随机噪声，无明显放电特征",
        "confidence": min(spread, 0.90),
        "severity": "normal",
    }
```

**拒判条件解析**：
- **top2 < 0.40**：最大两个扇区能量占比不足 40%（无明显相位集中）
- **max_amp < noise_threshold × 5**：最大幅值未显著超过噪声基底（5 倍以内）
- `noise_threshold` 使用 `median×2, p5×1.5, min_nonzero` 三者最大值，避免单一指标失效

### 7.2 严重等级判定

```python
def _determine_severity(amp_stats: dict) -> str:
    max_amp = amp_stats["max_amplitude"]
    p90 = amp_stats["p90"]

    if max_amp > 5000 or p90 > 3000:
        return "critical"   # 严重
    elif max_amp > 2000 or p90 > 1000:
        return "warning"    # 警告
    elif max_amp > 500:
        return "attention"  # 注意
    return "normal"         # 正常
```

| 严重等级 | 触发条件 | 说明 |
|---------|---------|------|
| **critical** | max > 5000 mV **或** P90 > 3000 mV | 严重放电，需立即处理 |
| **warning** | max > 2000 mV **或** P90 > 1000 mV | 一般报警，需关注 |
| **attention** | max > 500 mV | 注意观察，记录趋势 |
| **normal** | max ≤ 500 mV | 正常范围内 |

### 7.3 参考结果置信度

```python
# Bootstrap 采样后的置信度
confidence = best_count / total_samples  # 多数投票占比

# 示例: 50 次采样中 35 次判为内部气隙
confidence = 35 / 50 = 70%
```

### 7.4 特征值对比速查表

## 8. 适用场景与局限性

### 8.1 适用场景

| 放电类型 | 适用场景 | 准确率 |
|---------|---------|--------|
| 内部气隙 | 固体绝缘内部气泡、油中气泡 | ★★★★☆ |
| 电晕 | 导体尖端、边缘电场集中 | ★★★★☆ |
| 沿面 | 绝缘子表面污秽、爬电 | ★★★☆☆ |
| 悬浮 | 金属悬浮电位体 | ★★★☆☆ |

### 8.2 已知局限性

1. **混合放电**：多种放电类型同时存在时，当前算法仅返回多数投票结果，未做混合识别
2. **低信噪比**：强背景噪声下，s1_s4_ratio、cv 等特征可能失效
3. **数据量要求**：每种类型推荐 ≥500 条事件，低于 100 条时分类可靠性显著下降
4. **外部干扰**：外部电磁干扰产生的伪脉冲可能被误分类
5. **重复脉冲**：周期性重复脉冲（如逆变器干扰）可能被误判为悬浮放电

### 8.3 改进方向

- 引入**混合放电识别**：对 type_ratios >20% 的类型均标记为"疑似混合"
- 加入**时域特征**：上升时间、脉冲宽度等辅助判断
- **自适应阈值**：根据历史数据动态调整噪声阈值
